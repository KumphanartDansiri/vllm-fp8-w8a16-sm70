3.  **Step 1: Tokenization**
   - Raw text → sequence of tokens
   - Methods: Word-level, subword (BPE, WordPiece, SentencePiece), character-level
   - Example: "Hello, world!" → ["Hello", ",", "world", "!"]
   - Each token mapped to integer ID via vocabulary
   - Output: Sequence of token IDs: [id1, id2, ..., idN]

4.  **Step 2: Embedding & Positional Encoding**
   - Token IDs → dense vectors via lookup table (embedding matrix)
   - Shape: (batch_size, seq_len, d_model)
   - Problem: Transformers lack inherent sequence order awareness
   - Solution: Add positional encodings (sinusoidal or learned)
   - Result: X = E + P, where E is token embeddings, P is positional encodings
   - Shape remains (batch_size, seq_len, d_model)

5.  **Step 3: Transformer Block (Core Processing)**
   - A transformer consists of N identical layers (blocks)
   - Each block has:
     a. Multi-Head Self-Attention (MSA)
     b. Add & LayerNorm
     c. Position-wise Feed-Forward Network (FFN)
     d. Add & LayerNorm
   - I'll explain each sub-component precisely.

   **3a. Multi-Head Self-Attention:**
   - Input: X (seq_len, d_model)
   - Linear projections: Q = XW_Q, K = XW_K, V = XW_V (each d_model × d_model)
   - Split into h heads: Q_i, K_i, V_i each of shape (seq_len, d_k) where d_k = d_model/h
   - Attention scores: S = QK^T / sqrt(d_k)
   - Masking (for autoregressive): causal mask applied to S to prevent attending to future tokens
   - Softmax: A = softmax(S) → attention weights (seq_len, seq_len)
   - Weighted sum: O = AV → (seq_len, d_k)
   - Concatenate heads: O_concat = [O_1; O_2; ...; O_h] → (seq_len, d_model)
   - Output projection: O_final = O_concat W_O
   - Residual connection: X' = X + O_final
   - LayerNorm: X'' = LayerNorm(X')

   **3b. Feed-Forward Network (FFN):**
   - Input: X'' (seq_len, d_model)
   - Two linear layers with non-linearity: FFN(x) = max(0, xW_1 + b_1)W_2 + b_2 (or GELU/SiLU in modern models)
   - Typically expands to d_ff (e.g., 4×d_model) then projects back to d_model
   - Applied position-wise (same weights across all positions)
   - Residual connection: X''' = X'' + FFN(X'')
