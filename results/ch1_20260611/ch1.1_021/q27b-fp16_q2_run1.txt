3.  **Step-by-Step Breakdown:**

   **Step 1: Tokenization**
   - Input: Raw text string
   - Process: Split into subword tokens using a vocabulary (e.g., BPE, WordPiece, Unigram)
   - Output: Sequence of token IDs
   - Details: Handles unknown words, special tokens (BOS, EOS, PAD), vocabulary size V
   - Example: "Hello world!" → [101, 2345, 678, 102] (IDs)

   **Step 2: Embedding Lookup**
   - Input: Token IDs
   - Process: Map each ID to a dense vector of dimension d_model using an embedding matrix E ∈ ℝ^(V × d_model)
   - Output: Sequence of token embeddings X ∈ ℝ^(N × d_model), where N is sequence length
   - Details: Learnable parameters, captures semantic/syntactic information

   **Step 3: Positional Encoding**
   - Problem: Transformers lack inherent sequence order awareness
   - Solution: Add positional encodings P ∈ ℝ^(N × d_model) to token embeddings
   - Types: Sinusoidal (original) or learned (modern)
   - Output: X_pos = X + P ∈ ℝ^(N × d_model)
   - Details: Preserves relative/absolute position information

   **Step 4: Transformer Block(s) - Self-Attention Mechanism**
   - Input: X_pos ∈ ℝ^(N × d_model)
   - Linear Projections: Compute Q, K, V matrices
     - Q = X_pos W_Q, K = X_pos W_K, V = X_pos W_V
     - W_Q, W_K, W_V ∈ ℝ^(d_model × d_model) (or d_model × d_k for multi-head)
   - Multi-Head Attention:
     - Split into h heads: d_k = d_model / h
     - For each head i: Q_i, K_i, V_i
     - Attention scores: A_i = softmax((Q_i K_i^T) / √d_k)
     - Output per head: O_i = A_i V_i
     - Concatenate heads: O = Concat(O_1, ..., O_h) W_O
     - W_O ∈ ℝ^(d_model × d_model)
   - Residual Connection & LayerNorm:
     - X_att = LayerNorm(X_pos + O)
   - Details: Causal masking for decoders, attention weights sum to 1, √d_k scaling prevents vanishing gradients

   **Step 5: Feed-Forward Network (FFN)**
   - Input: X_att ∈ ℝ^(N × d_model)
   - Structure: Two linear layers with non-linearity (typically GELU or ReLU)
     - FFN(x) = max(0, x W_1 + b_1) W_2 + b_2 (or GELU)
     - W_1 ∈ ℝ^(d_model × d_ff), W_2 ∈ ℝ^(d_ff × d_model), d_ff typically 4×d_model
   - Residual Connection & LayerNorm:
     - X_out = LayerNorm(X_att + FFN(X_att))
   - Details: Position-wise, same transformation applied
