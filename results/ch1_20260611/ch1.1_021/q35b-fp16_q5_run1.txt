Here's a thinking process:

1.  **Understand User Requirements:**
   - Implement a thread-safe LRU cache in Python
   - Support `get(key)` and `put(key, value)` methods
   - Fixed capacity
   - Use only standard library
   - Include docstrings
   - Include pytest unit tests covering:
     - Eviction
     - Update
     - Concurrency

2.  **Core LRU Cache Design:**
   - Need a data structure that supports O(1) get and put operations
   - Standard approach: Doubly linked list + Hash map (dictionary)
   - Doubly linked list maintains order (most recent at head, least recent at tail)
   - Hash map maps keys to nodes in the linked list
   - When capacity is exceeded, remove the least recently used item (tail)
   - Thread safety: Use `threading.Lock` to protect concurrent access

3.  **Implementation Details (Standard Library Only):**
   - `collections.OrderedDict` could be used, but it's not thread-safe by itself. I could wrap it with a lock, but implementing a custom doubly linked list is more educational and gives full control. However, using `OrderedDict` with a lock is simpler and perfectly valid. Let's stick to the classic doubly linked list approach for clarity and to demonstrate understanding, but I'll make sure it's clean.
   - Actually, Python's `collections.OrderedDict` is fine, but implementing a custom node-based LRU is more robust for demonstrating thread safety and LRU mechanics. I'll implement a custom doubly linked list with sentinel nodes for easier management.
   - Thread safety: `threading.Lock` around `get` and `put` operations.

   Let's draft the structure:
   ```python
   import threading

   class _Node:
       def __init__(self, key=None, value=None):
           self.key = key
           self.value = value
           self.prev = None
           self.next = None

   class LRUCache:
       def __init__(self, capacity: int):
           if capacity <= 0:
               raise ValueError("Capacity must be positive")
           self.capacity = capacity
           self.cache = {}  # key -> Node
           self.lock = threading.Lock()

           # Sentinel nodes for head (most recent) and tail (least recent)
           self.head = _Node()
           self.tail = _Node()
           self.head.next = self.tail
           self.tail.prev = self.head

       def _add_to_head(self, node):
           # Add right after head
           node.prev = self.head
           node.next = self.head.next
           self.head.next.prev = node
           self.head.next = node

       def _remove_node(self, node):
           prev = node.prev
           nxt = node.next
           prev.next = nxt
           nxt.prev = prev

       def _move_to_head(self, node):
           self._remove_node(node)
           self._add_to_head(node)

       def _pop_tail(self):
           # Remove node before tail
           node = self.tail.prev
           self._remove_node(node)
           return node

       def get(self, key):
           with self.lock:
               if key in self.cache:
                   node = self.cache[key]
                   self._move_to_head(node)
                   return node.value
               return -1  # Or None, but -1 is common. I'll use None for clarity.

       def put(self, key, value):
           with self.lock:
               if key in self.cache:
                   node = self.cache[key]
                   node.value = value
                   self._move_to_head(node)
               else:
                   if len(self.cache) >= self.capacity:
                       # Evict LRU
                       lru_node = self._pop_tail()
                       del self.cache[lru_node.key]
                   new_node = _Node(key, value)
                   self.cache[key] = new_node
                   self._add_to_head(new_node)
   ```
